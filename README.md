A front-end reproduction of the *Penja Import Export* company website,
built as a school assignment to demonstrate mastery of HTML, CSS, and JavaScript.

## 🎯 Purpose
This project was assigned by my school to evaluate my ability to 
reproduce a real-world website using core front-end technologies.

- CSS3
- JavaScript

- JavaScript DOM interactions
